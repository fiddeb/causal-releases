Install the Causal investigation skill

The optional skill guides your agent through evidence capture, findings, occurrence times, Current State and handovers. It includes MCP setup instructions. Causal itself works without an agent or model account. The download contains instructions and examples, not the Causal application or a running MCP server.

Download and check

Download the Causal investigation skill ZIP and its SHA-256 checksum into the same folder. These files follow the skill published with this site; they can be updated independently of the application binary. The skill uses the Causal 2.0 payload schema. Update Causal if its live tool schemas lack a required capability.

In Terminal, change to the folder containing both downloads, then verify:

shasum -a 256 -c causal-investigation.zip.sha256

Continue only if it reports causal-investigation.zip: OK. If verification fails, download both files again. The checksum detects mismatched or corrupted bytes; download both files from this trusted site. Review the skill text before use.

Install in Codex

Extract the archive into your personal skill directory. The following commands refuse to overwrite an existing installation:

mkdir -p "$HOME/.agents/skills"
if [ -e "$HOME/.agents/skills/causal-investigation" ] || [ -L "$HOME/.agents/skills/causal-investigation" ]; then
  echo "Causal skill already exists. Follow the update instructions below."
else
  unzip causal-investigation.zip -d "$HOME/.agents/skills"
fi

The entrypoint must be ~/.agents/skills/causal-investigation/SKILL.md, alongside agents, references and the license. For project-only use, extract into that project's .agents/skills instead. Install one copy for the intended scope.

Codex normally detects local skills automatically. If the skill does not appear, restart Codex. You can invoke it explicitly with $causal-investigation. See the official skill documentation.

Connect the local MCP server

Install Causal using the macOS setup instructions. Find the executable and start the workspace:

command -v causal
causal --version
causal serve

Keep the service running. In another terminal, check existing Codex connections before adding one:

codex mcp list

If a causal connection already exists, inspect it and retain any deliberate custom workspace or key-file settings. For a new connection, use the absolute executable path reported above. Standard Apple Silicon Homebrew example:

codex mcp add causal -- /opt/homebrew/bin/causal mcp

The agent client starts causal mcp over stdio. The separate causal serve process owns the local workspace and API at http://127.0.0.1:7432. Do not add that address as an HTTP MCP endpoint. A remote-only client cannot start a binary on your Mac or access your local service through its own localhost.

Authentication uses the existing local credential file automatically. Do not paste keys into chat or configuration. Custom workspaces need a matching API URL and --key-file path; the installed skill's references/mcp-setup.md contains the complete procedure, including configuration examples and safe error handling. Codex configuration follows the official MCP documentation.

Reconnect the client after configuration changes, then ask your agent:

Use $causal-investigation to verify the Causal connection and list my investigations without changing anything.

A successful empty list is valid. Installing the skill does not itself configure or start MCP. Once connected, try a supplied observation with a known date and timezone and ask the agent to save it as a symptom and verify its event-time Timeline entry. Unknown times must remain explicitly unknown.

Update or remove

Download and verify the new ZIP. Review differences and preserve local edits. Move the existing skill folder to a backup location outside all skill discovery directories, then extract the replacement. Also check older installations under ~/.codex/skills and project-local copies to avoid duplicate or stale guidance. Keep the backup until you have verified discovery and a read-only MCP call.

To remove the skill, move its folder outside the skill directories. Remove the MCP client entry separately only if you also want to disconnect it. Neither action deletes investigations or stops a running Causal service.

Other agent clients

Use the client's documented local skill directory or load the extracted SKILL.md and its references as instructions. Configure its MCP connection with the absolute Causal executable as the stdio command and mcp as its argument. The included metadata names the MCP dependency causal. Client support for skill discovery differs; this archive does not register a hosted plugin.
